# Study Reminder

自宅にいる間、18:00〜23:00の間だけ勉強を促す通知を送り、無視したり他のアプリに逃げたりすると
だんだん通知がしつこくなっていく、自分専用のAndroidアプリです。

このREADMEには2通りの作り方を書いています。**PCにソフトを何もインストールできない場合は「方法A」**、
**Android Studioを入れられる場合は「方法B」**を読んでください。

---

## 方法A：PCに何もインストールせずスマホにインストールする（GitHub Actions）

ブラウザだけで完結します。PC側でのインストール作業は一切ありません。

### A-1. GitHubアカウントを作る

1. https://github.com にアクセスし、無料アカウントを作成（未登録の場合）

### A-2. リポジトリを作ってファイルをアップロードする

1. GitHubにログインした状態で右上の「+」→「New repository」
2. Repository name に `study-reminder` など好きな名前を入力し、「Create repository」（README等は追加しなくてOK）
3. 手元でこのzip（`StudyReminder.zip`）を**解凍**しておく（ダブルクリックでOK、インストール不要）
4. 作成されたリポジトリの画面で「uploading an existing file」というリンクをクリック
5. 解凍してできた `StudyReminder` フォルダの**中身**（`app` フォルダや `.github` フォルダ、`build.gradle.kts` など）をまとめてブラウザにドラッグ＆ドロップ
   - `.github` フォルダのように「.」から始まるフォルダも忘れずに含めてください（隠しフォルダとして表示されないOSがあるので、表示設定で「隠しファイルを表示」をONにしてから作業してください）
6. 一番下の「Commit changes」をクリック

### A-3. ビルドを実行する

1. リポジトリ画面上部の「Actions」タブを開く
2. 初回は「I understand my workflows, go ahead and enable them」のようなボタンが出るのでクリック
3. すでに自動でビルドが始まっているはずです（始まっていなければ左側の「Build APK」→右側の「Run workflow」から手動実行）
4. 黄色い丸（実行中）が緑のチェック（成功）になるまで数分待つ

### A-4. APKをダウンロードしてスマホに入れる

1. 緑のチェックが付いたビルドをクリックして開く
2. 一番下の「Artifacts」欄にある `study-reminder-apk` をクリックしてダウンロード（zipファイルが落ちてきます）
3. その中に `app-debug.apk` が入っています
4. これをスマホに転送します（GoogleドライブにアップロードしてスマホでDL／自分宛にメール／LINE Keepなど、やりやすい方法でOK）
5. スマホ側でそのAPKファイルをタップしてインストール
   - 初回は「不明なアプリのインストールを許可しますか」と聞かれるので、使っているアプリ（ファイル・Chrome・Gmailなど）に対して許可してください

もしビルドが赤い×で失敗したら、「Actions」タブ→失敗した実行→ログの赤字部分をコピーして教えてください。設定ファイルを直します。

## 方法B：Android Studioが使える環境がある場合

### B-1. Android Studioをインストールする

1. https://developer.android.com/studio にアクセスし、Windows/Macに合わせてダウンロード
2. インストーラーを実行し、基本的にすべて「Next」でOK（途中で追加のSDKコンポーネントをダウンロードするので、Wi-Fi環境で数分かかります）

### B-2. このプロジェクトを開く

1. Android Studioを起動
2. 「Open」を選び、解凍してできた `StudyReminder` フォルダ（このREADME.mdがある場所）を選択
3. 初回は自動でGradleの同期が始まります。数分待ちます
   - もし「Gradle wrapper is missing」といった案内が出たら、そのまま「OK」や「Use Gradle from: ‘wrapper’」を選べば自動生成されます
4. 右下や下部に赤いエラーが出ていなければOKです

### B-3. スマホと接続する

1. スマホの「設定 → デバイス情報 → ビルド番号」を7回連続タップして開発者モードを有効化
2. 「設定 → システム → 開発者向けオプション」で「USBデバッグ」をON
3. スマホをPCとUSBで接続し、スマホ側で「このパソコンを許可しますか？」が出たら許可
4. Android Studio上部のデバイス選択欄に自分のスマホが表示されるはず

### B-4. ビルドしてインストールする

1. 上部メニューの緑色の▷（Run）ボタンを押す
2. 初回はスマホ側に「提供元不明のアプリ」の確認が出ることがあるので許可
3. ホーム画面に「Study Reminder」というアプリが入ります

## 共通：アプリ内の初期設定（これをやらないと動きません）

アプリを開いたら、上から順番に設定してください。

1. **強制的に開くアプリを選択** → Studyplusなど、勉強开始時に開きたいアプリを一覧から選ぶ
2. **今いるWi-Fiを自宅として登録** → 自宅のWi-Fiに繋いだ状態でボタンを押す（先に位置情報の権限を許可しておく必要あり）
3. 権限ボタンを上から順に全部押して許可する
   - **通知の権限** → 許可しないと通知そのものが出ません
   - **位置情報の権限** → Wi-FiのSSID（名前）を取得するためにAndroidの仕様上必要です。取得した位置情報はどこにも送信されず、SSID判定にしか使いません
   - **使用状況へのアクセス** → 別画面が開くので、一覧から「Study Reminder」を探してONにする。これがないと「他のアプリに3分以上逃げた」の判定ができません
   - **アラームとリマインダー** → これがないと時間通りに通知が来ません（Android12以降で必要）
   - **バッテリー最適化の対象から除外** → これをしないと、スマホがスリープしている間にAndroidがアプリを停止してしまい、通知が来なくなることがあります
4. 一番上の「スケジュールを有効にする」をONにする

すべて緑（OK）になっていることを画面下の状態表示で確認してください。

## 共通：動作の仕組み（実装した仕様）

- 自宅のWi-Fiに接続中、かつ18:00〜23:00の間に「Study」通知を送る
  - 5分間ボタンを押さないと自動で再送する（23:00まで）
  - 「お休み」を押すとその日はもう通知しない（翌日18:00からまた通常通り）
  - 「勉強開始」を押すと選択したアプリを強制的に開く
- アプリを開いた後、他のアプリに3分以上戻らないと警告通知が来る
  - 1〜2回目：「もう少し頑張りましょう」／ボタンは「開始する・今日は休む・1時間後にまた通知する」
  - 3回目以降：「人はやるべきことを終わらせた時の…」／ボタンが「頑張ってみる・あきらめる・1時間後に通知する」に変化
  - 4回目以降はタイトルが「Sir.　………」に固定
  - 「開始する/頑張ってみる」で戻った後にまた3分以上離脱すると、レベルは1に戻らず続きからエスカレーションします
  - 「今日は休む」「あきらめる」を押すとその日は終了
- 23:00を過ぎたら、どんな状態であっても一切通知しません

## 共通：既知の制約・注意点

- **帰宅判定には最大15分ほどのズレが出ます。** Androidの仕組み上（WorkManager）、ごく短い間隔でバックグラウンド処理を繰り返すことができないための制約です。「帰宅した瞬間ピッタリ」ではなく「帰宅後15分以内」に最初の通知が来るイメージです。
- 「使用状況へのアクセス」権限がないと、3分離脱の判定ができず警告が一切出ません。手順5を必ず行ってください。
- メーカー独自のバッテリー節約機能（Xiaomi・OPPO・Huaweiなど）が強い端末では、上記の設定をしても裏側でアプリが止められることがあります。その場合は端末の「自動起動」「バックグラウンド制限」設定側も個別に確認してください。
- Wi-FiのSSID取得はAndroidの仕様上、位置情報サービス（GPSなど）がONになっている必要がある機種があります。SSIDが正しく登録できない場合は、設定の位置情報をONにしてから再度お試しください。

## 共通：コードの場所

- `app/src/main/java/jp/example/studyreminder/`
  - `MainActivity.kt` — 設定画面
  - `Engine.kt` — 状態遷移のロジック本体（仕様の心臓部）
  - `NotificationHelper.kt` — 通知の文言・ボタンの組み立て
  - `AlarmScheduler.kt` — 5分後・1時間後などの予約
  - `ForegroundMonitorService.kt` — 「3分離脱」の監視
  - `Prefs.kt` — 設定・状態の保存（SharedPreferences）

文言（通知のタイトルなど）を変えたい場合は `NotificationHelper.kt` の中の文字列を書き換えて、再度Runボタンを押せば反映されます。
